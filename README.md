# Edu.dev — Personal Portfolio & Landing Page

A clean, responsive landing page showcasing freelance digital services including web development, e-commerce, and custom business systems.

🔗 **Live site:** [edudev-landing.vercel.app](https://edudev-landing.vercel.app)

---

## About

This is my personal portfolio and services landing page. It presents the digital solutions I offer to businesses — from Shopify stores to custom management systems — along with pricing plans and featured projects.

Built as a single-file HTML project with no frameworks or dependencies, optimized for fast load times and mobile responsiveness.

---

## Features

- Fully responsive design (mobile, tablet, desktop)
- Services section with detailed offerings
- Monthly maintenance plans with tiered pricing
- Portfolio section with live project links
- WhatsApp and Instagram direct contact integration
- Smooth scroll navigation
- No external dependencies — pure HTML, CSS, and vanilla JavaScript

## Getting Started

No build step required. Just open `index.html` in your browser or deploy directly to any static hosting provider.

```bash
git clone https://github.com/eduardodevsn/edudev-landing.git
cd edudev-landing
open index.html
```

---

## Deployment

Deployed on **Vercel** via automatic GitHub integration. Any push to `main` triggers a new deployment.
